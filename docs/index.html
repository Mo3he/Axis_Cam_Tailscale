Add the camera to your tailnet and authenticate with a URL or auth key.

I want to reach camera services

Use local HTTP or SOCKS proxies and configure the access pattern supported by the app.

Questions

Good to know

Can every camera application use the tailnet?

Not with the standard userspace build. Firmware services cannot directly route to tailnet peers; use the app's proxies where supported.

Should I use a ROOT build?

The standard build is recommended. ROOT variants have broader access but are limited to older AXIS OS versions.

Can I change signing variants in place?

The README notes that changing vendor signing identity may require uninstalling and reinstalling.
